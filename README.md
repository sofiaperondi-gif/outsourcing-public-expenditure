# Outsourcing and Public Expenditure

Contract-level analysis of public service outsourcing and its relationship with public expenditure dynamics in European public procurement (2011–2021). Developed as part of a research dissertation supervised by Prof. Jesús Ferreiro (University of the Basque Country, UPV/EHU).

## Data
Global Public Procurement Database (GPPD), Eurostat, World Bank and Manifesto Project Database.

## Contents

- **Data cleaning & dataset creation** — R scripts that clean the raw sources and build the working dataset.
- **Merging** — scripts that merge the harmonized country-level sources into the final panel.
- **Econometric analysis** — main estimation scripts (panel-data models).
- **Robustness checks** — alternative specifications and sensitivity analyses.
- **Reports (.Rmd)** — detailed write-ups that walk through the work and findings in narrative form. These are the best starting point to understand the project before diving into the scripts.

## Where to start
Read the `.Rmd` reports first for an overview of the methodology and results, then explore the folders above for the underlying code.
